# Changelog

Notable changes to Dockmesh, loosely following [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
This file is generated by [changie](https://changie.dev) from `.changes/`; don't edit it by hand.
Every user-visible pull request adds a fragment under `.changes/unreleased/`
(`changie new`). Pull requests users won't notice (CI, refactoring, tests) carry the
`no-changelog` label instead. Releases up to and including v0.3.3 predate this file; their
notes are on the [GitHub releases page](https://github.com/Dockmesh/dockmesh/releases).

Release notes on GitHub and the `release-manifest.json` asset of each release are generated
from this file by `scripts/relmanifest`, so it follows a strict format:

- A release header is `## [X.Y.Z] - YYYY-MM-DD [severity]`, where severity is `security`
  (update as soon as possible), `recommended` or `normal`. `changie batch` writes it; see
  `RELEASING.md`.
- Text between the header and the first `###` is the release summary. An optional line
  `Minimum upgrade from: X.Y.Z` there names the oldest version that can upgrade directly.
- Subsections are `### Highlights`, `### Added`, `### Changed`, `### Fixed`, `### Security` and
  `### Upgrade notes`, one per fragment kind; each holds `- ` bullets (indented lines continue
  a bullet). A fragment's body is one line.
- `### Highlights` holds three or four plain-language lines the app shows first in its
  "what's new" notes. They summarise entries that are also listed in the other subsections.
  A minor release (`X.Y.0`) must have them; patch releases may leave them out.
- A Security bullet of the form `- GHSA-xxxx-xxxx-xxxx (critical|high|moderate|low): Title`
  is published as an advisory.
- Every Upgrade notes bullet is something a person has to do after upgrading and starts with
  `[id, audience]`, where `id` is a short kebab-case name that stays fixed and audience is
  `all` or `admins`: `- [re-login, all] Sign in again after the upgrade.`

## [Unreleased]

Entries for the next release are the fragments in `.changes/unreleased/`; `changie batch`
moves them into a release section.
